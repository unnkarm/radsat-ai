# 🌍 RADSAT

> AI-powered Earth Observation dashboard for visualizing satellite imagery and geospatial insights.

## Overview

RADSAT is a modern frontend application for an Earth Observation platform. It provides an intuitive interface for exploring satellite imagery, monitoring geospatial events, and displaying AI-generated analyses.

This repository currently contains the frontend built with React and TypeScript. Backend services and AI inference are planned for future releases.

## Features

- 📊 Modern dashboard
- 🛰️ Satellite imagery interface
- 🗺️ Interactive geospatial visualization
- 📈 Analytics and insights
- 📱 Responsive UI

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Bun

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/radsat.git
cd radsat
```

Install dependencies:

```bash
npm install
```

or

```bash
bun install
```

Start the development server:

```bash
npm run dev
```

or

```bash
bun dev
```

The application will be available at:

```
http://localhost:5173
```
